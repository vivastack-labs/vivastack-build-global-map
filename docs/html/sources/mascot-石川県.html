「ひゃくまんさん」のデザイン利用について

石川県観光PRマスコットキャラクター「ひゃくまんさん」（以下「キャラクター」という。）の利用は、
  石川県の観光PRや観光ブランド力の向上等に寄与すると認められる場合に利用の許諾をすることとします。

申請について

キャラクターを利用しようとする方は、あらかじめ、石川県の許諾を受ける必要があります。
　許諾を受けるためには、以下の書類を提出する必要があります。
　※1キャラクターを利用する物件の種類により提出書類が異なりますため、ご注意ください。
　※2許諾審査には、十分にデザイン案を確定させたもの（修正可能な段階）が必要となります。
         簡易的なイメージ（デザイン変更の可能性を大いに含むもの）の提出はご遠慮ください。
    ※3申請から許諾まで、通常7～10営業日程度の時間をいただいております。
　　（申請書の修正が発生する場合には、更に日数を要することがあります。）
　　  お早めに申請くださいますよう、お願いいたします。

申請にあたっての注意点

次の文書は必ず申請前にご確認ください

　※令和6年4月1日更新

　※平成27年9月1日更新

・石川県観光PRマスコットキャラクター「ひゃくまんさん」の利用に関するQ&A（PDF：389KB）
　※令和3年12月13日更新

▷上記文書に記載した遵守事項のうち、次の点については誤った申請がなされる
　   ことが多いため、特にご注意ください。

・指定色で印刷していない
　　デザインタイプ１・２・５は、DIC620あるいは「青金」での印刷が必須です。
　　※1衣服等、上記指定色で印刷できない場合は、別途ご相談ください。
　　※2キャラクター金色部分を箔押しすることは可能

・クリアスペースを設けていない
　　キャラクターの周囲には、印刷可能スペースに応じてクリアスペースを設けてください。
 ①印刷可能スペースが10cm×10cm以上の場合
　　→「ひゃくまんさんの高さ×0.1」 以上のクリアスペースを設けてください。
　　②印刷可能スペースが10cm×10cm未満の場合
　　→「ひゃくまんさんの高さ×0.05」 以上のクリアスペースを設けてください。
　　※上記規定は、許諾番号（©2013石川県ひゃくまんさん＃●●●●）にも適用されます。

・ キャラクターを最小サイズ未満で使用している
　　キャラクターは、15mm×15mm以上の大きさで使用してください。
 ※デジタル使用の場合は、視認性が保たれていればサイズは問いません。
　　　(各人の使用媒体によりサイズが変動するため）

・商号や商品名に「ひゃくまんさん」の冠を使用している
　　キャラクターに性格付けやイメージ付けがされたり、特定企業をイメージさせたりするため、　
　　商号や商品名に「ひゃくまんさん」の冠を使用してはいけません。
 ※同カテゴリの商品との区別の意味で「ひゃくまんさんver.」などと表示することは可能

・許諾番号を記載していない
　　商品タグや利用する物件（商品）に、許諾番号は必ず記載してください。
　　表記例：©2013石川県ひゃくまんさん＃●●●●

▷なお、次の場合は利用を許諾しません。

(1)キャラクターを立体として表現したもの
　(2)法令及び公序良俗に反するものと認められる場合
　(3)県の信用又は品位を害するものと認められる場合
　(4)第三者の利益を害するものと認められる場合
　(5)特定の個人、政党、宗教団体を支援し、又は支援するおそれがあると認められる場合
　(6)風俗営業等の規制及び業務の適正化に関する法律（昭和23年法律第122号）第2条に定める営業を行う者
　　 が利用する場合及びこれらの者に商品等を販売する場合
　(7)キャラクターの利用によって誤認又は混同を生じるおそれがあると認められる場合
　(8)キャラクターのイメージを損なうおそれがあると認められる場合
　(9)キャラクターの著しい変形その他キャラクターの利用が適当でないと認められる場合
　(10)その他、キャラクターの利用が適当でないと認められる場合

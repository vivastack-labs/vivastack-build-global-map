湖北省丨知音江城——武汉非遗美食之旅
发布时间：2026.02.06

行程节点

户部巷、粮道街、昙华林（武汉过早习俗、武汉小吃、扬子江传统糕点）→黄鹤楼公园（黄鹤楼传说、武汉岳飞传说）→晴川阁（武汉大禹治水传说）→古琴台（伯牙子期传说）→汉口非遗圈（汉绣传习馆、汉派石雕、金石器物全形传拓）→汉剧博物馆（汉剧）→吉庆街（老通城豆皮、蔡林记热干面、武汉五芳斋汤圆、汪玉霞传统糕点、四季美汤包）→汉口历史风貌街区（德华楼传统小吃）

非遗美食技艺及特色项目

蔡林记热干面制作技艺、武昌鱼制作技艺、老通城豆皮制作技艺、扬子江传统糕点制作技艺、曹祥泰酥京果制作技艺、武汉五芳斋汤圆制作技艺、汪玉霞传统糕点制作技艺、德华楼传统小吃制作技艺、四季美汤包制作技艺、黄鹤楼传说、武汉岳飞传说、伯牙子期传说、汉剧、汉绣

非遗旅游体验

线路以武汉非遗美食为核心，巧妙串联历史文脉与城市烟火，将蔡林记热干面、老通城豆皮等非遗代表性项目，与黄鹤楼传说、伯牙子期传说等深度融合，让游客在舌尖品味烟火气的同时，感受武汉城市文化。

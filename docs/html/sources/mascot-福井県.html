「Juratic」デザインの使用について

「Juratic」キャラクターのデザインを使用する場合には、事前に申請が必要です。
『福井県公式恐竜ブランド「Juratic」キャラクター等の使用に関する要綱』をお読みの上、
福井県が商品化権管理業務を委託している（株）Ｃファクトリーまたは福井県誘客推進課に申請書をご提出ください。

着ぐるみの貸出について

ラプト、サウタン、ティッチーの着ぐるみの貸出を希望される場合には、事前に申請が必要です。
福井県誘客推進課まで申請書をご提出ください。
日程・イベント内容を確認させていただいたうえで、貸出可能かどうか連絡をさせていただきます。

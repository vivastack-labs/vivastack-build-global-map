けんみん文化祭ひろしまでは、けんみん文化祭ひろしまの開催が県内外に広く周知されるよう、マスコットキャラクター（ブンカッキー）の着ぐるみの貸出や、ブンカッキーのデザインとイメージソング未来の風の使用許諾を行っております。​

申請方法

着ぐるみの貸出し

着ぐるみ​

〇予　約　電話で予約状況を確認してください。
〇申請書　メールで申し込んでください。
※参考資料（企画書、計画書、申請者概要等）があれば添付して下さい。
〇申請先 　kanbunka@pref.hiroshima.lg.jp　
〇承　認　承認まで１週間程度いただく場合がございます。
〇受　取　当事務局へ取りにおいでください。
（約H120cm×約W130cm×約D60cm）※持ち出す際のサイズとなります。
〇返　却　使用期間終了後、当事務局へ持参してください。​

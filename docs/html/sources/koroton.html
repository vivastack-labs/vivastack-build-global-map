ぼくは「ころとん」！

はじめまして！

両手をあげたころとん

「はじめまして！ぼくはころとんだころ。じこしょうかいするころ！」

自己紹介（じこしょうかい）

ころとん

まん丸なからだと赤いほっぺがとくちょう。

ころころ太ったかわいらしいこぶたをイメージした血色（けっしょく）のよい健康優良児（けんこうゆうりょうじ）。

名前（なまえ）

ころとん

誕生日（たんじょうび）

10月10日（TONTONの日）

性別（せいべつ）

おとこのこ

特技（とくぎ）

耳をピクピクうごかすこと

笑顔のころとん

「前橋市はぶた肉の産出額（さんしゅつがく）が全国でトップクラスなんだころ！」

両手をあげたころとん

「そんな前橋のおいしいぶた肉料理をみんなにしってもらうため、そして、前橋のイメージアップのためにがんばっているころ！」

笑顔のころとん

「もし、ぼくをまちで見かけたら、「ころとん！」 て声をかけてほしいころ♪」

ころとんはどんなことをしるの？

左手をあげたころとん

「ぼくは、いろいろなところで前橋のことや、ぶた肉のことを知ってもらうための活動をしてるころ！」

お辞儀をしているころとん

「したのリンクでぼくのことをたくさんしょうかいしているころ！このページはふりがながふってないから、おとなの人といっしょに見てほしいころ！」

両手をあげたころとん

「ぼくのグッズもたくさん出てるころ♪これからもどんどん活動していくから、おうえんよろしころー！」

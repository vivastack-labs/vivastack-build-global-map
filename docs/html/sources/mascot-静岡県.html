2月14日は静岡県イメージキャラクター“ふじっぴー”の誕生日 HAPPY BIRTHDAY インスタライブを開催します

静岡県

2022年2月10日 14時00分
２月14日（月）12時10分から、静岡県イメージキャラクターのふじっぴーの誕生日をお祝いして、インスタライブを実施します。
▼日時
令和４年２月14日（月）12時10分から12時30分まで
▼視聴方法
下記のＵＲＬまたは、インスタグラム上で、ふじっぴー公式インスタグラムのアカウント「＠fujippy_shizuokaken」を検索し、アクセス
https://instagram.com/fujippy_shizuokaken?utm_medium=copy_link
▼内容
・ふじっぴーの自己紹介
・お誕生日のお祝い
・ふじっぴーのお友だちからのビデオレター　等
▼プロフィール
静岡県イメージキャラクター「ふじっぴー」
生年月日：２月14日
得意なこと：スポーツは何でも得意
誕生のきっかけ：平成15年に行われた第58回国民体育大会と第３回全国障害者スポーツ大会のキャラクターとして誕生。国体終了後に静岡県のイメージキャラクターとなる。
名前の由来：「富士山」「ハッピー」「ピース」「ピープル」の言葉を組み合わせてつけられている。
デザインイメージ：静岡県のシンボル富士山がモチーフ。体の青は、駿河湾のブルーを表している。おしりがプリッと跳ね上がっているのは、しずおか県の頭文字「し」をかたどっている。

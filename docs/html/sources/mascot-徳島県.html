徳島県マスコットキャラクター「すだちくん」イラスト利用申請のご案内

2017年4月19日
  • Tweet

「すだちくん」のイラストは、商品のパッケージ、イベントのチラシ、パンフレット、Webサイトなどに原則無料でご利用いただけます。ご利用には事前の利用申請が必要です。以下の手順に沿って、メールにて申請をお願いいたします。

ご利用の前に（使用取扱要綱）

「すだちくん」のイラストは、正しいイメージを保ちながら多くの方に親しんでいただくため、使用のルール「すだちくん使用取扱要綱」が定められています。申請の前に必ずご一読ください。

すだちくん使用取扱要綱（まず初めにお読みください）

  • すだちくん使用取扱要綱（R8.8.1改正） (PDF:190 KB)

利用申請の流れ

【STEP 1】申請書を作成しメールで送る

「（第1号）使用承認申請書 」に必要事項を記入し、ご提出ください。

すだちくん利用申請書およびメールの送付先はこちら

  • （第1号）使用承認申請書 (Word97-2003:45 KB)

【提出方法及び提出先】
・メールの場合：chijisenryakukyoku@pref.tokushima.lg.jp
・持参する場合：県庁3階 知事戦略局までお持ちください。

書き方がわからない場合はこちらを参考にしてください

  • すだちくん使用承認申請書（記載例） (PDF:87 KB)

【STEP 2】審査・承認連絡

申請書の内容を「すだちくん使用取扱要綱」に基づき、県にて審査します。承認された場合、承認番号を記載した「使用承認書」を返送します。
原則、使用するイラストの付近に承認番号を明記の上、使用をお願いいたします。

申請内容に変更があった場合はこちら

すだちくんのイラスト・画像の使用について

1．使用範囲

公益的な利用だけでなく、営利利用についてもお使いいただけます。

2．使用料

「すだちくん」を商品として使用する場合の利用承諾料(使用料）は、無償とします。

※商品とは、営利を目的とする販売商品（キャラクターグッズ、商品パッケージ等）。

●「すだちくん」のプロフィール

この画像を許可なく複製、改変、使用することを禁じます。

個人のホームページなどに無断で掲載することは、著作権侵害になる場合があります。

よくあるご質問

Q．申請書の添付書類「（2）申請者の略歴、現況等を示すもの」とはどのような書類を指していますか。

A．会社概要や申請者の状況がわかる書類をご提出ください。

Q．申請から承認までどれくらい時間がかかりますか。

A．土日祝を除き、1週間程度で承認の可否についてご連絡させていただきます。

Q．既存のイラスト以外でオリジナルのイラストを作ることは可能ですか。

A．オリジナルのイラストを作成していただくことも可能です。「すだちくん使用取扱要綱」に基づいて、審査を行います。

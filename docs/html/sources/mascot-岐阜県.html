ミナモの着ぐるみの貸出しについて

ミナモの着ぐるみの借受けを希望される場合は、

1.『ミナモ着ぐるみ借受の手引き』をよくご覧いただき、借受条件等をご確認ください。

ミナモ着ぐるみ借受の手引き [PDFファイル／208KB]

2.『ミナモ着ぐるみ借受の手引き』記載の「貸出機関」へ、お電話にて空き状況の確認のうえ、仮押さえをしてください。
　※管轄の「貸出機関」へお電話をお願いします。

3.仮押さえ後、「貸出機関」へメール又はFAXにて借受依頼書をご提出いただきます。

借受依頼書 [Wordファイル／46KB]

4.借受希望日に「貸出機関」にお越しいただき、着ぐるみを借受けます。借受け時に『マニュアル』をお渡ししますので、事故等の無いように、またミナモらしい動きの厳守をお願いいたします。
　※着ぐるみの受け取り・返却については、開庁時間内（平日8時30分から17時15分まで）にお願いいたします。配送等による受け渡しには対応しておりません。
　※「チームミナモ」の派遣は、令和8年3月をもって終了しました。

ミナモデザインの利用について

ミナモデザインデータを様々な商品のパッケージに利用したり、オリジナルのミナモグッズの作成などにご利用いただけます。

＜注意事項＞
・私的な利用以外は利用許諾が必要です（無料）。
・イラストレーター、JPEGデータの利用を希望される方は、地域振興課までお問い合わせください。
・申請から許諾通知書をお出しするまでに約2週間程度いただいております。また、審査にあたり追加で資料をご提出いただく場合があります。

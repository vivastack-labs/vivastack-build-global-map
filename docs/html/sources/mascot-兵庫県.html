兵庫県お口の健康マスコットはばタン

歯と口腔の健康づくりについての関心を高めることを目的とし、シンボルマークを作成しました。

兵庫県お口の健康マスコットシンボルマークの使用について

シンボルマークの使用を希望される方は、下記の「兵庫県お口の健康マスコットシンボルマーク使用取扱要綱」をご覧のうえ、「兵庫県お口の健康マスコットシンボルマーク使用承認申請書（様式第1号）」を下記兵庫県健康増進課あてメールにて提出してください。

(注)申請書類の提出からデザイン使用承認まで1週間程度お時間をいただいております。

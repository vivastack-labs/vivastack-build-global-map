ボランティア募集

鉾田市では、正式競技であるスポーツクライミング競技が開催され、首都圏をはじめ全国各地から多くの方の来場が予想されます。第74回国民体育大会鉾田市実行委員会では、全国から参加される方々に対しおもてなしの心でお迎えするため、大会運営・開催準備を支える「いきいき茨城ゆめ国体鉾田市ボランティア」を募集します。この機会に国体にスタッフとして参加し、市を挙げて盛り上げていきましょう。

大会期間

【リハーサル大会】 　2019年6月8日（土）・9日（日）
【いきいき茨城ゆめ国体（鉾田市開催日）】 　2019年10月4日（金）・5日（土）・6日（日）

募集内容

区分 主な活動内容
受付・会場案内 競技会場等における受付、案内及び資料配布等
会場サービス 休憩所におけるドリンクサービス、弁当引換、接待等
環境美化 競技会場内外の美化、清掃活動
飾花・栽培 競技会場等を装飾するプランター飾花の栽培
その他 上記のほか、競技運営に関する活動

募集要件

ボランティア実施時に高校生以上（平成16年4月1日以前に生まれた方）の方。
ただし、18歳未満の方は保護者の同意が必要となります。

申込期限

2018年12月10日（月）まで　2019年3月29日（金）までに延長となりました！！

募集を締め切りました。ご応募ありがとうございました。

申込方法

「いきいき茨城ゆめ国体鉾田市ボランティア登録申込書」（様式第1号）に必要事項を記入し、下記の申込先まで持参、郵送、FAX、Eメールでお申込みください。ただし、保護者の同意が必要となる場合は、持参もしくは郵送に限ります。
※グループで申込みの場合は、「いきいき茨城ゆめ国体鉾田市ボランティア登録申込書」（様式第1号）と「団体・グループ登録名簿」（様式第2号）の両方を提出してください。

活動について

具体的な活動内容は、ボランティア登録後に活動希望調査等を参考に決定します。ご希望に添えない場合がありますので、予めご了承ください。
また、必要に応じて研修会等を実施する場合があります。

報酬及び交通費等

活動及び研修等への参加に係る報酬は無償です。（交通費も自己負担）
活動及び研修にあたっては、必要に応じて傷害保険等に加入します。

個人情報の取扱い

申込者の個人情報については、第74回国民体育大会鉾田市実行委員会が大会準備及び運営のためのみに使用します。
※茨城県への情報提供に同意された方は、茨城県へ情報提供いたします。

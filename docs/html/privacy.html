プライバシーポリシー

「せかいをめぐる地図」を利用するときの、情報の取り扱いについて説明します。

アクセス解析

このサイトのページにはアクセス解析ツールを組み込んでいません。検索欄に入力した文字は、ブラウザ内で一覧の絞り込みに使います。

Cookie

このサイトのページは Cookie を設定しません。

端末に残る情報

  • 地図で選んだエリアや国・地域などは、URL の「#」以降に記録されます。この部分はページのリクエストに含まれず、ブラウザの閲覧履歴に残ることがあります。
  • ページや地図データは、ブラウザの設定に応じてキャッシュに残ることがあります。

閲覧履歴やキャッシュは、ブラウザの設定から削除できます。

配信

地図は登録やログインなしで利用でき、端末の現在地は取得しません。ページを開いたときや国・地域を選んだときは、必要に応じて配信サーバーから地図データを読み込みます。

配信にあたり、接続元の IP アドレスや、アクセスしたページ・地図データのパスなどの通信情報が処理される場合があります。配信事業者による情報の取り扱いは、その事業者のプライバシーポリシーに従います。

外部サイトへのリンク

データの出典などのリンクから外部サイトに移動した場合は、移動先のプライバシーポリシーが適用されます。

運営者と連絡先

運営者は VivaStack です。

誤りや不具合は World Atlas の GitHub Issues へご報告ください。閲覧・投稿には、リポジトリへのアクセス権が必要です。投稿には、名前やメールアドレスなどの個人情報を書かないでください。
